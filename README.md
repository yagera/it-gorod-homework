# ДЗ ML

Две задачи, обе обязательны. Сдаются два CSV — `task-1.csv`, `task-2.csv` (+ файл «Общение с ИИ»). **Дедлайн: 22.11.2026, 12:00.**

| Задача | Что | Метрика | Формат |
|---|---|---|---|
| T1 | прогноз `yearly_cv_processed` на 2024 по 505 департаментам | MAPE | `department_id,yearly_cv_processed`, 505 строк, значения > 0, порядок id как в sample |
| T2 | классификация муниципальных НПА по коду `NNN.NNN.NNN` (58 классов) | Macro-F1 | `row_id,code`, 10001 строка, `row_id` как в sample, коды только из train |

## Как воспроизвести
Нужны `uv` и Python 3.11. Данные не в git: выданные файлы положить в `data/raw/task1/` и `data/raw/task2/` (`data/raw/task/` — только условие, код его не читает).
```
uv sync --frozen --no-group dl   # dl (torch) нужна только для эмбеддингов
make submit      # t1 + t2 + проверка формата → outputs/task-1.csv, outputs/task-2.csv
```
Проверено в чистом клоне: `uv sync --frozen` (с группой `dl`) + `make submit` ≈ 3 мин 18 с (8 ядер), пик памяти ≈ 2,9 ГБ; md5 обоих CSV совпали с сданными.

Остальные цели: `make lint | test | ci`, `make check-time-split`, `make t1-experiment`, `make t2-experiment | t2-tune | t2-tune2 | t2-stability | t2-swapdate` (долго, пишут в `outputs/`). Все цели — обёртки над `uv run itgorod …`; запускать из корня репозитория. Тесты на синтетике, `data/` не нужен.

## Итоги
**T1 — планка без обучаемых параметров:** прогноз = `ratio` отдела за 2023 (`yearly_cv_processed / active_projects_count`) × `active_projects_count` из test. Валидация только по времени (≤2021→2022, ≤2022→2023, правило утечки A): MAPE 2,84% / 3,06%. Сглаживание ratio (A) от планки неотличимо (в пределах шума), A+D и Ridge хуже (записи 9–10). MAPE на 2024 неизвестен; ошибка фолда 2023 в основном от резких обвалов `active_projects_count` у нескольких отделов (запись 11), малые значения таргета (y < 200) дают лишь 1,1% / 6,3% суммы ошибки.

**T2 — TF-IDF (word + char) + LinearSVC, C=1, первые 2000 символов текста, fit на всём train.** OOF Macro-F1: **0,84** (основная схема: StratifiedKFold 5, дубли тела в одном фолде) / **0,80** (контрольная: StratifiedGroupKFold по органу). Оценки на test нет.

## Ограничения оценки
- **T2: оценка включает сигнал порядка сбора данных.** Дата выгрузки в шапке документа сильно связана с классом: 56 из 58 классов имеют ≥95% строк в одной из 4 групп дат, мода класса по дате даёт accuracy 0,76 (majority 0,35). Оценки 0,84 / 0,80 включают этот сигнал; без номера и дат ориентир ≈0,70–0,75 (абляция «без номера и дат»: 0,7525 / 0,7033, грубая — убирает заодно дату акта). Дата выгрузки в test распределена как в train, поэтому на test сигнал, вероятно, доступен так же. Подмена даты выгрузки случайной в valid снижает Macro-F1 до 0,65 / 0,59: модель сильно опирается на дату (это чувствительность к ложной дате, а не оценка «без даты»). Оставлять ли номер и даты в модели, решает автор.
- **Выбор по той же CV.** Усечение и C выбирались по основной схеме на тех же данных, оценка победителя оптимистична; σ по фолдам ≈0,01 сопоставима с разностями многих конфигураций.
- **Схема по группам дат вырождена** (классы почти не пересекаются между группами): Macro-F1 ≈ 0,007, шапку она не измеряет.
- **T1:** 2 фолда, 503–505 строк; MAPE 2024 не известен.
- **Не проверено:** почти-дубли документов, разложение «номер / дата акта / дата выгрузки», причина сдвига доли классов в декабре 2025. Полный список — «Известные ограничения» в `docs/DECISIONS.md`.
